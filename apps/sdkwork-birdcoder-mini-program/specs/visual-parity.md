# Visual Parity Matrix

This initialization creates a representative native workbench state page. It does not claim pixel or workflow parity with the H5 ChatPage.

| State | Native target evidence | Source parity status |
| --- | --- | --- |
| Loading | Branded hero, progress indicator, runtime initialization copy | Scaffold only |
| Empty/initialization | Package/config/build capability summary and retry action | Scaffold only |
| Ready | Product name, version, and active profile | Scaffold only |
| Permission denied | Dedicated access-denied card | Behavior shape aligned; source screenshot pending |
| Unavailable | Dedicated service-unavailable card and retry | Behavior shape aligned; source screenshot pending |
| Error | Dedicated unknown-error card and retry | Behavior shape aligned; source screenshot pending |

Accepted drift for this round:

- Native WeChat touch-first card layout replaces the H5 desktop/chat composition during initialization.
- H5 tokens, complete typography, icons, chat transcript, composer, settings, login, and interactive screenshot comparison remain future conversion work.
- No production or live user data is included in fixtures or screenshots.
